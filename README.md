# Angel Motwani | Personal Portfolio

**Live site:** https://motwaniangel05-sudo.github.io

A personal portfolio website built with plain HTML, CSS and JavaScript for [Btech Data Science]. It introduces who I am, what I study, and the projects I've built as a B.Tech Data Science student at MPSTME, NMIMS Mumbai.

## Sections
- **About:** who I am, my education and what I'm exploring
- **Projects:** BACKBONE, IPL Match Winner Predictor, Olist SQL Analysis and CodeSage, with a category filter
- **Skills & interests:** languages, tools and AI concepts
- **Contact:** email, LinkedIn and GitHub

## Features
- Dark purple and blue theme, responsive on phone and laptop
- Animated hero with a particle-network background, typing text and a data graphic
- Count-up stats, scroll animations and a skills ticker
- Filterable project cards with hover effects
- Respects the "reduce motion" setting for accessibility

## Built with
HTML, CSS and vanilla JavaScript (no frameworks, no templates). Hosted free on GitHub Pages.
